# 如何配置用户友好界面

本文记录如何把系统默认的“表格 + 表单”页面，包装成更适合普通用户使用的业务界面。

本次示例页面为：

```text
办公用品目录与库存
```

改造后的效果是：用户在一个页面里可以查看物品库存、筛选物品、查看流程动态，并发起申领或采购入库。

![办公用品目录与库存总览](./assets/用户友好界面_欧阳荣康_assest/01-office-supplies-overview.png)

## 一、先确定页面要解决什么问题

### 第一步：选择一个真实业务场景

不要为了美化而单独做一个演示页面，最好选择实际会使用的业务。

本次选择的是办公用品管理，因为它本身有比较明确的使用场景：

- 普通员工需要查找物品并发起申领。
- 物资管理员需要关注库存和采购入库。
- 部门领导需要查看和处理相关流程。

### 第二步：明确用户进入页面后的动作

原始表格适合维护数据，但对普通用户不够直观。

因此页面改造时，先明确用户最常做的动作：

1. 看库存是否充足。
2. 搜索某个办公用品。
3. 查看物品详情。
4. 发起申领或入库流程。
5. 查看当前有哪些流程正在处理。

后续页面布局就围绕这些动作展开。

## 二、确定页面改造思路

### 第一步：保留原始数据能力

用户友好界面不是重新做一套业务系统，而是在原有表格和表单外面加一层更易读的展示。

所以底层仍然使用平台已有的数据源、表单和流程。

页面美化只负责：

- 换一种方式展示数据。
- 把常用操作放到更明显的位置。
- 减少用户直接面对大表格的压力。

### 第二步：把页面拆成几个区域

本次页面拆成以下区域：

| 区域 | 作用 |
| --- | --- |
| 标题区 | 告诉用户当前页面是做什么的 |
| 数据概览 | 快速显示物品总数、正常库存、低库存等 |
| 库存概览 | 用矩阵方式展示不同分类的库存状态 |
| 流程动态 | 展示申领和采购入库的进行中记录 |
| 物品目录 | 用卡片或列表展示物品数据 |
| 操作入口 | 发起申领、发起采购入库、查看详情 |

这样用户不用先理解表格字段，就能先看到业务状态。

### 第三步：减少没有必要的视觉装饰

页面风格尽量保持干净。

本次页面采用：

- 全局白色背景。
- 浅色边框。
- 少阴影或无阴影。
- 统一字体粗细。
- 主要按钮保持醒目。
- 状态颜色只用于表达业务含义。

不建议使用过重的阴影、渐变背景或装饰性图形，否则容易和办公系统风格不统一。

## 三、把表格数据改成卡片

### 第一步：确定卡片显示哪些信息

表格中字段很多，但卡片不需要全部展示。

卡片只保留用户最关心的信息：

- 物品名称
- 物品编码
- 物品分类
- 规格型号
- 可用库存
- 安全库存
- 库存状态
- 存放位置

其他字段可以放到详情里查看。

![物品卡片视图](./assets/用户友好界面_欧阳荣康_assest/02-office-supplies-card-view.png)

### 第二步：用状态帮助用户判断

卡片中不要只显示数字，还要让用户一眼知道当前是否正常。

例如：

| 状态 | 展示方式 |
| --- | --- |
| 库存正常 | 绿色标签 |
| 低库存 | 橙色或红色标签 |
| 停用物品 | 灰色标签 |

库存数量可以配合进度条显示，方便用户快速判断库存是否充足。

### 第三步：保留列表视图

卡片适合浏览，但不适合大量核对字段。

所以页面可以保留“卡片视图 / 列表视图”切换。

默认显示卡片视图，需要核对详细字段时再切换到列表视图。

## 四、把操作入口放到用户容易找到的位置

### 第一步：把常用操作放到页面右上角

例如：

```text
发起流程
```

点击后以下拉方式展示：

- 办公用品申领
- 采购入库

这样用户不需要先进入某个流程列表，再去找新增按钮。

### 第二步：详情入口尽量自然

物品卡片和流程动态都可以点击进入详情。

如果整张卡片都可以点击，就不一定需要额外显示“查看详情”四个字。

这样页面会更干净。

### 第三步：操作仍然调用平台原有能力

页面可以做美化，但关键操作不要绕开平台原有逻辑。

例如：

- 发起流程尽量调用对应流程的新增动作。
- 查看详情尽量调用平台原有编辑或查看动作。
- 流程审批仍然交给原流程表单处理。

这样可以避免权限、按钮、流程状态异常。

## 五、增加搜索、筛选和分页

### 第一步：提供搜索和筛选

卡片展示更友好，但数据多了以后仍然需要筛选。

建议保留：

- 关键词搜索
- 物品分类筛选
- 库存状态筛选
- 存放区域筛选
- 排序方式

筛选项不宜太多，保留用户最常用的即可。

### 第二步：增加分页

卡片一次展示太多会影响阅读。

建议每页最多展示 20 条。

超过 20 条时再分页。

这样页面不会太长，也更容易浏览。

## 六、添加流程动态区域

### 第一步：把相关流程集中展示

本次页面把两个流程放到同一个“流程动态”区域：

- 办公用品申领流程
- 办公用品采购入库流程

这样用户不用分别进入两个流程列表查看。

### 第二步：只显示有处理价值的数据

流程动态区域不一定要显示所有记录。

建议优先显示：

- 进行中的流程
- 待审批的流程
- 最近更新的流程

已经完成的流程可以放到单独台账页面，避免占用主页面空间。

### 第三步：按最新时间排序

流程动态建议按更新时间倒序展示。

也就是最新发生变化的流程排在最前面。

这样用户进入页面后，优先看到最近需要关注的事项。

## 七、保存后重点测试

页面完成后，不只看样式，还要测试操作是否正常。

测试内容：

1. 数据是否能正常显示。
2. 卡片数量是否正确。
3. 搜索和筛选是否有效。
4. 卡片视图和列表视图是否能切换。
5. 发起流程是否能进入正确页面。
6. 点击记录是否能进入详情。
7. 不同角色看到的数据是否符合权限。

## 八、最终效果

改造后，页面不再只是原始表格。

用户可以在一个页面中完成：

- 查看库存概览。
- 查找办公用品。
- 判断库存是否正常。
- 发起申领或采购入库。
- 查看当前流程动态。

这种方式会比原始表格多一层前端展示，但更适合普通业务用户使用，也更接近真实办公系统中的业务页面。
